# Compiler Design DSL

## Project Description
This project implements a simple DSL compiler using Flex and Bison.

## Features
- Lexical Analysis
- Parsing
- AST Construction
- Semantic Analysis
- Intermediate Code Generation

## Tools Used
- Flex
- Bison
- GCC
- VS Code

## Sample Input
a = 4 + 5;

## Sample Output
Valid Statement
AST Created
Semantic Analysis Successful
t1 = 4 + 5
a = t1
